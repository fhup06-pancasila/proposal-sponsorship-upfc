# Proposal Sponsorship Pancasila Football Club

Halaman proposal pengadaan jersey Pancasila FC dengan penawaran kemitraan **Platinum — Mitra Utama Jersey** dan **Gold — Mitra Jersey**. Area depan jersey menyediakan hingga tiga slot Main Sponsor. Dukungan operasional tim menjadi pilihan kerja sama tambahan.

## Menjalankan

Buka `index.html` di browser atau sajikan folder ini melalui server web statis. Halaman menggunakan HTML, CSS, dan JavaScript tanpa proses build atau instalasi dependensi.

## Fitur

- Tampilan responsif dan ilustrasi interaktif penempatan sponsor pada desain jersey terbaru.
- Cetak surat pengajuan formal A4 beserta formulir konfirmasi sponsorship.
- Formulir perusahaan dengan pilihan paket dan rincian dukungan, ringkasan untuk ditinjau, serta tautan WhatsApp ke PIC.
- Cetak formulir secara terpisah, dengan isian yang tersedia atau sebagai lembar kosong.

Formulir tidak menggunakan database atau mengirim data otomatis. Pengisi perlu membuka WhatsApp dan mengirim pesan yang telah disiapkan.

## Dokumen

- `Proposal-Sponsorship-Pancasila-FC.pdf`: surat pengajuan dan formulir konfirmasi.
- `Formulir-Konfirmasi-Sponsorship-Pancasila-FC.pdf`: formulir terpisah.
- `PANDUAN-PENGAJUAN.md`: panduan penggunaan proposal.

Desain aktif menggunakan `Jersey design FIX.jpeg`. Berkas desain sebelumnya dan referensi penempatan sponsor turut disertakan sebagai aset sumber.
